# pairwise-skill-targeting

范围技能指向远处时，指示圈套在错误的地面高度，屏幕射线只与一个水平面求交，上坡时圈子陷进地里；指示器半径按固定屏幕像素算，相机 FOV 变化后与实际范围不符；目标筛选用碰撞体中心，大体型怪站在圈边缘时选不中；友军与敌军共用一个碰撞层，治疗技能选中了敌人；最大距离按水平面二维距离算，高低差大的目标超出实际射程；指示圈穿墙显示，隔墙的敌人看起来在范围内；指示器与施放时的判定各写一套，显示能打到实际打不到；移动端拖拽没有死区，手指轻微抖动时指示器乱跳；目标在施法途中死亡，指示器仍然锁着尸体；多目标上限按遍历顺序取，最近的敌人反而没被选中。gameplay/skill_targeting.py 是核心，tests/test_skill_targeting.py 15个红。要修的是：多点地形求交；按 FOV 投影半径；按包围体判定；分层筛选；三维距离；视线遮挡；共用判定；拖拽死区；目标失效清理；按距离排序。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
